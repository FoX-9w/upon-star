## 书写规则（写给所有贡献者/未来的自己）

1. **本地是单一真相源**：语料在本目录（`agent/knowledge/`）维护，扣子知识库只是上传副本。改语料 → 本地改 → 重新上传扣子。
2. **可翻译结构**：字段与章节名固定，正文才翻译。出海时复制一份 `lang: en` 的平行文件即可，不要把解读写死在 JS 字符串里。
3. **每条一个文件**：文件名 = `id.md`，id 用拼音/英文短名，不含中文与空格。
4. **合规口径**：全文不得出现禁用词（占卜/算命/预测/命运定论等正面宣称，词表见 `../system-prompt.md` 铁律 1）；「使用边界」是保护性条款，禁止表述可以出现（如「不构成……建议」）。
5. **长度**：单条 200–400 字。太短模型没得引用，太长 RAG 检索会切碎语义。
