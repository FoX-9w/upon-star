1. 项目目录结构

先了解整个项目的文件组织方式：

divination-homepage/ ├── _shared/ │ └── fonts/ # 全站字体文件 │ ├── CrimsonPro-Regular.ttf │ ├── CrimsonPro-Bold.ttf │ ├── Italiana-Regular.ttf │ ├── Outfit-Regular.ttf │ ├── Outfit-Bold.ttf │ └── PoiretOne-Regular.ttf │ ├── assets/ # 全站素材资源 │ ├── div-nav.js # 快捷导航组件 │ ├── share.js # 分享功能组件 │ ├── liuyao-data.js # 六爻卦象数据 │ ├── hero-bg.jpg # 首页英雄区背景 │ ├── hero-bg_1.jpg # 首页英雄区背景（当前使用） │ ├── divider-bg.jpg # 分割线背景 │ └── divider-bg_1.jpg # 分割线背景（当前使用） │ ├── articles/ # 文章目录（新建） │ └── article-template.html # 文章模板（复制使用） │ ├── fusion/ # 中西融合页面 │ ├── bazi-standalone.html # 八字排盘 │ ├── astrology-standalone.html # 星盘排盘 │ └── fusion-compare.html # 中西对照 │ ├── divination-homepage.html # 首页 ├── liuyao.html # 六爻占卜 ├── tarot.html # 塔罗占卜 ├── lenormand.html # 雷诺曼占卜 └── daily-fortune.html # 每日运势
提示：你自己的壁纸图片放在 assets/ 目录，文章页面放在 articles/ 目录。

2. 添加新文章

把公众号文章搬到网站，只需 4 步：

复制模板文件

将 articles/article-template.html 复制一份，重命名为你的文章名：

# 好的命名：有意义的英文或拼音
articles/qian-gua.html        # 乾卦解读
articles/liuyao-case-love.html # 六爻感情案例
articles/tarot-spread.html    # 塔罗牌阵解读

修改文章信息

打开新文件，搜索 <!-- EDIT 标记，逐一修改：

<!-- EDIT: 修改为你的文章标题 -->
<title>乾卦解读：天行健 · Upon Star</title>

<!-- EDIT: 分类标签，可选 east / west / fusion -->
<span class="article-cat east">周易 · 64卦</span>

<!-- EDIT: 文章标题 -->
<h1 class="article-title">你的文章标题</h1>

<!-- EDIT: 副标题/摘要 -->
<p class="article-subtitle">一句话摘要</p>

<!-- EDIT: 日期 / 阅读时间 / 作者 -->
<span>2026年7月26日</span>
<span>4分钟阅读</span>
<span>Upon Star</span>

填入正文内容

在 <div class="article-body"> 和 <!-- 正文内容到这里结束 --> 之间填入你的公众号文章内容。支持的格式：

类型写法说明
段落<p>文字</p>普通正文段落
小标题<h2>标题</h2>章节大标题（金色）
子标题<h3>标题</h3>小节标题
加粗<strong>文字</strong>金色强调文字
引用<blockquote>...</blockquote>左侧金线引用框
列表<ul><li>...</li></ul>带金色星号前缀
图片<img src="图片路径">自动圆角边框
高亮框<div class="highlight-box">金色提示框
分割线<hr>金色渐变线
公众号文章转换技巧：公众号的加粗用 <strong>，引用文字用 <blockquote>，图片直接用 <img> 标签。大部分内容直接粘贴到 <p> 标签里即可。

保存并预览

保存文件后，在浏览器中打开 http://localhost:8765/articles/你的文件名.html 预览效果。

3. 替换背景壁纸

你准备自己画壁纸，替换步骤很简单：

首页英雄区背景

当前使用的背景图是 assets/hero-bg_1.jpg。

把你的画导出为 JPG 格式

建议尺寸：1920×1080 或更大，文件大小控制在 500KB 以内（可用在线压缩工具）。

放入 assets 目录

将你的壁纸文件放到 assets/ 目录。

# 推荐命名方式
assets/hero-bg_2.jpg    # 第二版壁纸
assets/hero-bg_3.jpg    # 第三版壁纸

修改首页引用

打开 divination-homepage.html，搜索 hero-bg，找到这行：

/* 在 .hero-bg 中 */
.hero-bg {
  background: url('assets/hero-bg_1.jpg') center center / cover no-repeat;
}

将文件名改为你的壁纸：

.hero-bg {
  background: url('assets/hero-bg_2.jpg') center center / cover no-repeat;
}

分割线背景

同理，分割线背景当前使用 assets/divider-bg_1.jpg，修改方式相同——搜索 divider-bg 替换文件名即可。

注意：壁纸建议使用深色调（暗色系），因为网站是深色主题。如果壁纸偏亮，可以在 .hero-overlay 中调暗透明度（把 rgba(4,4,8,0.7) 改大）。
保留旧壁纸：不要删除旧的 hero-bg_1.jpg，万一想换回来直接改文件名即可。

4. 更新首页文章卡片

文章写好后，需要在首页把「敬请期待」卡片改成真实链接：

找到对应的卡片

打开 divination-homepage.html，搜索 card-coming-soon，你会看到 5 个待发布文章卡片。

修改链接和样式

将 href="#" 改为文章路径，去掉 card-coming-soon 类名：

<!-- 修改前 -->
<a href="#" class="card east card-coming-soon" aria-label="...">
  ...
</a>

<!-- 修改后 -->
<a href="./articles/qian-gua.html" class="card east" aria-label="...">
  ...
</a>

更新卡片信息

修改卡片内的标题、日期等文字，使其与文章一致：

<div class="card-cat east">周易 · 64卦 <span class="card-badge soon-badge">科普</span></div>
<div class="card-title">你的文章标题</div>
<div class="card-meta">7月26日 · 4分钟阅读</div>
badge 处理：文章已发布后，可以把 soon-badge 类去掉，或改为 card-badge（不带 soon）。也可以把 科普 文字改为 已发布 或直接删掉 badge。

5. 文件命名规范

类型规范示例
文章页面小写英文或拼音，短横分隔qian-gua.html
壁纸图片用途-序号hero-bg_2.jpg
文章图片文章名-序号qian-gua-01.jpg
分类前缀东方=east / 西方=west / 融合=fusioneast-qian-gua.html
避免：中文文件名（部分服务器不支持）、空格、特殊符号。统一用英文短横线 - 分隔单词。

6. 付费解读配置

深度解读内容通过付费墙锁定，免费展示基础排盘/牌面信息，付费解锁深度分析与真人解读预约。

配置文件位置

所有付费相关配置在 assets/premium-lock.js 文件顶部的 CONFIG 对象中：

var CONFIG = {
  wechatId: 'uponstar_wx',           // 微信客服号
  wechatQrImage: '',               // 微信二维码图片路径
  disclaimer: '...',                  // 免责声明文案
  service: { ... }                            // 唯一服务：深度解读牌面
};

微信客服模式（当前方案）

用户在占卜结果页点击「微信客服 获取深度解读」→ 扫码添加微信 → 与解读师沟通确认问题 → 微信支付完成付款 → 解读师提供一对一深度解读服务。

当前付费渠道：仅微信客服（uponstar_wx）。公共领域可获取的占卜知识内容均为免费开放，唯一付费服务为「深度解读牌面」（Deep Reading，¥88/次）。

修改服务定价

在 CONFIG.service 对象中修改深度解读服务的名称、描述和价格：

service: {
  id: 'deep-reading',
  name: '深度解读牌面',
  desc: '由专业解读师根据卦象/牌面提供一对一深度分析...',
  price: '88',        // 价格（元）
  unit: '次',          // 单位
  icon: '✦'            // 图标符号
}

合规要点

1. 服务定性：所有解读服务统一定性为"传统文化研究与心理探索参考"，避免使用"算命""预测""改运"等表述。

2. 免责声明：每个页面底部均显示免责声明，首页 footer 已更新为完整版合规文案。

3. 收款合规：深度解读服务通过微信客服渠道预约，微信支付完成付款。本站不涉及任何第三方交易平台。

4. 税务提醒：个人年收入超过 50 万建议考虑注册个体工商户；月流水超 1 万需关注增值税申报。

7. 常见问题

Q: 文章里要放图片怎么办？

把图片放到 articles/images/ 目录（没有就新建），然后在文章中引用：

<figure>
  <img src="images/qian-gua-01.jpg" alt="乾卦图示">
  <figcaption>乾卦六爻全阳</figcaption>
</figure>

Q: 公众号文章有排版格式，能直接粘贴吗？

公众号文章的 HTML 格式比较复杂，建议只提取纯文字内容，然后用模板提供的标签重新排版。核心就几种：<p> 段落、<h2> 小标题、<blockquote> 引用、<img> 图片。

Q: 能加多张图片吗？

可以，直接在 <div class="article-body"> 里放多个 <img> 或 <figure> 标签。

Q: 壁纸支持什么格式？

JPG（推荐）、PNG、WebP。建议 JPG，文件小、加载快。首页背景建议 1920×1080 以上，分割线背景建议 1920×200。

Q: 怎么改文章的分类颜色？

文章头部的 article-cat 标签支持三种分类颜色：

<!-- 东方玄学（红棕色）-->
<span class="article-cat east">周易 · 64卦</span>

<!-- 西方占卜（蓝色）-->
<span class="article-cat west">塔罗 · 牌阵</span>

<!-- 中西融合（紫色）-->
<span class="article-cat fusion">融合 · 解读</span>

Q: 文章写好了怎么让用户看到？

两步：① 把文章文件放到 articles/ 目录 ② 在首页 divination-homepage.html 把对应卡片的 href="#" 改为文章路径。用户就能从首页点击进入文章了。
